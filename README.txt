Our Family Root — User / Read-Only Viewer

Version: V1.32

This copy is a viewer-only edition of the family tree.
Users can explore the family data and interactive features, but cannot add, edit, delete, or export family data from the UI.

Available viewer features:
- Search family members
- Click members to inspect family details
- Focus branch / ancestor-and-descendant snake view
- Timeline
- Insights
- More Details
- My Family
- Reset to the founding generation (Late Kaalu baa - Late Basanti)
- Photo lightbox
- Mouse/touch pan and zoom
- Theme toggle
- Mobile Back gesture support

Admin data updates are made in the separate Admin project. To publish updated family data to this viewer, replace family-data.js with the latest admin backup and keep the viewer app.js / styles.css / index.html unchanged.
